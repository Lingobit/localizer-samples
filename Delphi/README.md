Create Localized Files, then Run Localized. The prebuilt Win32 Delphi EXE includes forms, menus, dialogs, collections and image selection. No Delphi compiler is needed to localize or run it. v2 updates the main form caption in the archived EXE resource; executable code is unchanged. Rebuilding Pascal sources requires Delphi. The supplied German translation covers all form UI; bundled Delphi RTL error strings retain English.

Both revisions contain matching German form translations. Copy the whole revision to a writable folder first. Close the sample before creating localized files. To practise Scan, copy v1/Sample.loc beside the v2 input under a new project name and Scan for Changes; the main caption changes in v2.
